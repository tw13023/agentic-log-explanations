### 2. BGL 兩次 Full Run 比較分析

**Previous (0301, pre-fix) vs Current (0313, post-fix)，同一 model (gpt-5.1)，差異來自 prompt 修正。**

#### Core Metrics

| Metric | Previous (0301) | Current (0313) | Change |
|--------|:---:|:---:|:---:|
| Predicted anomalies | 6,295 | 5,850 | -445 |
| TP | 5,844 | 5,843 | -1 |
| FP | 451 | 7 | **-444** |
| Success rate | 100% | 100% | -- |
| Verification passed | 6,295 (100%) | 5,850 (100%) | -- |

Anomaly 數量下降 445，幾乎全數來自 FP 減少（451->7）。TP 僅差 1，screener 的 recall 不變。FP 大幅改善可能是因為 screener model 有更新或 threshold 調整（需確認）。

#### Token Usage

| Metric | Previous | Current | Change |
|--------|:---:|:---:|:---:|
| Avg prompt tokens | 3,433 | 5,933 | **+72.8%** |
| Avg completion tokens | 557 | 563 | +1.1% |

| Total tokens | 25,117,492 | 38,000,025 | +51.3% |

Prompt tokens 增加 ~73%，與 HDFS 的 +99% 趨勢一致，主因是 E5 normal evidence 在 prompt 中提供了更完整描述。Completion 幾乎不變（+1.1%），說明 LLM 輸出長度不受 prompt 長度影響。

#### Latency

Latency 增加 ~32%，主要受 prompt tokens 增加影響（更多 input = 更長 prefill time）。
