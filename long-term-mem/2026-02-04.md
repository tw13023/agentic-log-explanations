## Session 3: HDFS Pipeline Fix & Dataset-Specific Prompts

### Objective
Fix HDFS screener predicting all sessions as normal, and prevent LLM from hallucinating BGL signatures for HDFS data.

### Problems Identified

#### 1. Screener Predicting All Normal
- **Symptom**: `04_pipeline_HDFS.ipynb` screener predicted 0 anomalies on test set (should be ~17)
- **Root Cause**: `src/screener.py` was padding sequences to full `max_seq_len` (15,166 tokens)
- **Impact**: Mean pooling diluted the actual signal with ~14,000+ padding zeros → all sessions looked "normal"

#### 2. LLM Hallucinating BGL Signatures
- **Symptom**: All 17 HDFS anomalies got signature `RAS_KERNEL_FATAL__DATA_STORAGE_INTERRUPT` (a BGL signature!)
- **Root Cause**: `src/prompt_builder.py` had BGL-specific examples hardcoded in prompts
- **Impact**: LLM copied the example instead of deriving signatures from actual HDFS log content

### Solutions Implemented

#### 1. Screener Fix (`src/screener.py`)
```python
# BEFORE: Pad to full max_seq_len (BAD - dilutes signal)
if input_ids_tensor.size(1) < self.max_seq_len:
    pad_len = self.max_seq_len - input_ids_tensor.size(1)
    input_ids_tensor = F.pad(input_ids_tensor, (0, pad_len), value=0)

# AFTER: Only truncate, don't pad (for single session)
def screen_session(self, session):
    # Truncate only, no padding needed for single inference
    if len(input_ids) > self.max_seq_len:
        input_ids = input_ids[:self.max_seq_len]
        segment_ids = segment_ids[:self.max_seq_len]

# AFTER: Pad only to batch max (for batch inference)
def screen_sessions(self, sessions, batch_size=8):
    # Pad to max length IN THIS BATCH, not model max_seq_len
    max_len = max(len(s['input_ids']) for s in batch)
```

Additional fixes:
- Added `segment_ids` clamping: `segment_ids = torch.clamp(segment_ids, 0, self.segment_vocab_size - 1)`
- Fixed position_ids argument: `logits = self.model(input_ids, segment_ids, position_ids=None, attention_mask=mask)`

### Key Learnings

1. **Mean pooling + excessive padding = disaster**: Padding to max model length dilutes the signal when using mean pooling. Only pad to batch max.

2. **LLMs copy examples literally**: If you put a complete JSON example in the prompt, the LLM will often copy it verbatim instead of generating new content. Put the schema in the system prompt, not a filled-in example.

3. **Dataset-specific prompts matter**: Component names, severity levels, and example signatures should match the dataset being analyzed to prevent hallucination.
