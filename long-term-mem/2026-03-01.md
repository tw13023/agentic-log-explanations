## Today's Accomplishments

### 1. Prompt Fix A/B Test ✅

**背景：** 前次 HDFS 500-anomaly run 中有 24 sessions verification FAIL（4.8%），分為 4 個 category。針對這些 category 新增 4 條 CRITICAL RULES（8-11）到 HDFS prompt。

**新增規則：**
- Rule 8: NEVER use "STRUCTURAL" as evidence_span
- Rule 9: evidence_spans MUST NOT be empty
- Rule 10: MUST output exactly 3 claims (observation, pattern_match, contrast)
- Rule 11: claim text MUST include keywords from cited evidence lines

**A/B Test 方法：**
- 24 known FAIL sessions 作為固定 test set
- Baseline: 不含 rules 8-11 的原始 prompt（git stash 暫存再 run）
- Treatment: 含 rules 8-11 的新 prompt

**Results:**

| Metric | Baseline | Prompt Fix | Change |
|--------|:---:|:---:|:---:|
| Verification PASS | 13/24 (54.2%) | 19/24 (79.2%) | **+25.0 pp** |
| Correctness (C) | 3.06 | 3.56 | **+0.50** |
| Coherence (Co) | 3.79 | 3.25 | -0.54 |
| Evidence (E) | 4.56 | 4.67 | +0.11 |

**Per-Category Impact:**

| Category | Baseline C | Fix C | Baseline FAIL | Fix FAIL |
|----------|:---:|:---:|:---:|:---:|
| A-empty_claims (n=7) | 1.64 | 3.93 | 7 | **0** |
| B-empty_spans (n=3) | 2.50 | 4.00 | 3 | **0** |
| C-STRUCTURAL (n=8) | 3.88 | 3.12 | 3 | 3 |
| D-keyword (n=6) | 3.75 | 3.67 | 0 | 2 |

Rule 8-11 完全解決了 Cat A 和 Cat B，但在 Cat C/D 有輕微回退。Coherence 下降來自 Cat C 的 signature naming 問題。

### 3. Key Findings ✅

**llama3.1:8b 是明確的最佳 model，原因：**

1. **Verification pass rate 差距巨大** — 79.2% vs 第二名 33.3%（qwen2.5:14b）
2. **唯一能遵循 prompt rules 的模型** — Cat A/B 達到 0 FAIL，其他 4 模型全部 FAIL
3. **Correctness 最高** — 3.54 vs 第二名 2.67
4. **Latency 最低** — 6771ms，是 qwen2.5:14b (22346ms) 的 1/3
5. **Structured JSON compliance 最佳** — mistral/phi3 幾乎完全無法遵循格式（87.5-91.7% FAIL）

**重要觀察：**
- 參數量更大（14b）不等於更好的 instruction following
- gemma2/qwen2.5/phi3/mistral 對我們的 structured JSON prompt 遵循度極差
- 這更加強化了論文的 framing：「framework 穩健性不完全依賴 model scale，但 model choice 確實重要」
