#### Stratified 為什麼是 non-deployable tautology

核心問題：Stratified strategy 要求「每個 signature 至少分配 1 個 session」，但 signatures 是 LLM 產生的 output，在 gating 階段（deciding which sessions to send to LLM）尚不可用。

- **Gating** = pre-LLM decision: 「此 session 要不要送去 explain？」
- **Caching** = post-LLM decision: 「此 session 已 explain 過，下次遇到同 signature 可以重用」
- Stratified 需要知道 signatures → 需要先跑 LLM → 不是 gating

數學上：當 K >= num_signatures 時，Stratified 必定 100% coverage。B=0.20 時 K=1259 >> 360 signatures(BGL)，所以 100% 是恆真式，不是實驗發現。

#### 修正方案

1. **移除 Stratified**：從策略比較中完全移除
2. **保留 Upper Bound**：作為 privileged reference ceiling（標記 "privileged"）
3. **移除 B=0.20 vertical line**：不再暗示任何特定 budget 是最佳
4. **重定位 Uncertainty**：best deployable gating strategy
5. **提升 Quality Invariance**：從附屬 finding 升級為 Key Finding
6. **Alpha ablation 降級為 Ablation**：確認 alpha=1.0（pure uncertainty）最佳，Combined/Novelty 失敗

### 6. Follow-up: Alpha Sensitivity Figure 改動

#### B=0.20 -> B=0.50
Alpha sensitivity figure 從 B=0.20 改為 B=0.50，因為 B=0.20 對 Uncertainty 無特殊意義（74.7% BGL / 62.5% HDFS），B=0.50 才是實用 budget（>91% BGL / >95% HDFS coverage，~50% token 節省）。

#### HDFS Phase Transition 診斷
HDFS 在 alpha sweep 出現 phase transition（alpha 0.0-0.9 coverage 停在 16%，alpha=1.0 跳到 95%）。

Root cause: HDFS 的 novelty signal (n(x)) 方差比 uncertainty (u(x)) 大 11.1 倍：
- HDFS u(x): std=0.0171, n(x): std=0.1888, ratio=11.1x
- BGL u(x): std=0.0516, n(x): std=0.1357, ratio=2.6x

任何 alpha < 1.0 時 novelty 完全主導 combined score，導致相同的 session 集合被選中。alpha=0.9→1.0 時 71% 的被選 session 改變。

GB "下降" 是視覺假象：0.3278 vs 0.3151，只差 1.27pp，被雙 y 軸 auto-scale 放大。

#### Key Finding 5 修正（Evidence Grounding as Discriminating Dimension）

原始措辭錯誤：稱 HDFS 為 "compact, positional evidence content"（實際上 HDFS log lines 比 BGL 更長更大）。

修正後重點：
1. **BGL sessions 固定 10 lines（sliding window）** → uniform structure，LLM 可靠解析
2. **HDFS sessions 1-55 lines（variable length）** → 需要 LLM 處理更長更多變的 context
3. **HDFS evidence sessions 含 compact outcome labels**（如 `exceptions=0`）→ LLM 誤讀為操作缺失
4. **Evidence Grounding 獨立於 C/Co**（Pearson r < 0.10）→ 確認為獨立品質軸
5. **BGL 所有 20 個 E=4 皆來自 contrast claims (Claim 3) 的 E5 描述失準**
6. 保守結論：evidence grounding quality is sensitive to session length variability and the semantic structure of evidence sessions
